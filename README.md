## Overview

ModulAir provides a Eurorack-format virtual modular environment on iOS and macOS with a growing library of modules, CV routing via virtual patch cables, and Audiobus and AUv3 integration.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **ModulAir** delivers the features you need in a clean, intuitive package.

</div>

## Key Features

| Feature | Description |
|---------|-------------|
| **Patch Cables** | Virtual patch cables connecting modules with CV and audio signals |
| **Module Library** | Oscillators, filters, envelopes, sequencers, and effect modules |
| **AUv3 Support** | Host ModulAir as an AUv3 plugin inside any compatible DAW on iOS |
| **MIDI CV** | Convert MIDI notes and CC to CV signals for modular integration |
